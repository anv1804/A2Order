# 🤖 QUY TẮC BẤT BIẾN CHO AI AGENT & LẬP TRÌNH VIÊN (AGENT GUIDELINES)

Tài liệu này là **nguyên tắc hoạt động tối cao** khi phát triển mã nguồn trong dự án **A2Order**. Bất kỳ AI Agent hoặc lập trình viên nào tham gia vào dự án đều **BẮT BUỘC** phải tuân thủ nghiêm ngặt các quy tắc dưới đây.

---

## 🛑 BỘ QUY TẮC BẮT BUỘC (CRITICAL INVARIANTS)

1. **Bảng màu Bất biến (Donezo Forest Green Style)**:
   * **TUYỆT ĐỐI CẤM** tự ý bịa màu lạ, cấm dùng màu xanh dương công nghệ đại trà, cấm màu cam/đỏ chói.
   * Toàn bộ UI bắt buộc dùng các token màu tại [`docs/01-technical-specs/design-tokens-palette.md`](./01-technical-specs/design-tokens-palette.md):
     * Nền tổng thể: `bg-surface-canvas` (`#F4F5F6`)
     * Thẻ/Panel: `bg-surface-card` (`#FFFFFF`), `rounded-3xl`, viền `border-surface-border`
     * Màu chính/Nút: `bg-brand-900` / `bg-brand-800` (Xanh rừng trầm `#12372A`)
     * Nhãn Tag/Badge: `bg-brand-100 text-brand-800` (Sage mint)
2. **Không comment dài dòng vào code**: Code ngắn gọn, tối ưu, tự tường minh (self-documenting). Không giải thích lan man trong file code.
3. **Quy tắc Kiểm tra trước khi Code**:
   * Chức năng này có thực sự cần thiết không?
   * Hệ thống đã có sẵn chưa (tránh viết trùng lặp)?
   * Có cần phải viết lại không, hay tái sử dụng được?
4. **Quy tắc Không đoán mò / Bịa đặt**:
   * Khi gặp bất kỳ điểm nào chưa rõ hoặc không biết: **Bắt buộc phải hỏi lại người dùng**.
   * Tuyệt đối không tự suy diễn, không bịa đặt khi chưa có dẫn chứng cụ thể.
5. **Quy tắc Tách biệt Interface / Types**:
   * **CẤM** khai báo `interface` hoặc `type` trực tiếp bừa bãi trong các file component hay logic code.
   * Tất cả types/interfaces bắt buộc phải nằm trong thư mục quy chuẩn: `types/` (Client) hoặc `@a2order/shared` (Dùng chung).
6. **CẤM DÙNG `alert()`, `confirm()`, `prompt()` MẶC ĐỊNH**:
   * Bắt buộc sử dụng hệ thống feedback chuẩn hóa: `toast.success()`, `toast.error()`, `toast.warning()`, `toast.info()`.
   * Xác nhận hành động: `const ok = await confirmDialog({ title, message, confirmText, cancelText, variant })`.
7. **Quy chuẩn Icon**:
   * Bắt buộc dùng component `<Icon name="..." />` từ `@/components/ui`, dùng bộ Lucide Icons chuẩn, cấm cài thêm thư viện icon khác.
8. **Chống Spam & Tính toán Server-Side**:
   * Mọi thao tác submit quan trọng bắt buộc dùng `useAntiSpamAction` gắn `x-idempotency-key`.
   * Giá tiền, chiết khấu, tổng tiền tính 100% tại Server, không bao giờ tin client.
9. **Tài liệu đi trước Code (Docs-First)**:
   * Khi làm chức năng mới, tạo spec trong `docs/02-features/Fxx-.../SPEC.md` theo đúng mẫu `TEMPLATE_FEATURE.md`.
10. **Bất biến Đa thuê thuê (Multi-Tenant Invariant)**:
    * Mọi câu query dữ liệu bắt buộc lọc theo `storeId`.
